# Usage statistics

For calculating, updating, and displaying the multi-model usage table and widget, follow the [ai-usage-stats skill](.agents/skills/ai-usage-stats/SKILL.md) and the shared [update-usage skill](.claude/skills/update-usage/SKILL.md) for Claude Code, Codex, Antigravity, Meta Muse, Grok, and Cursor. Calculate Codex usage for the current local calendar day and previous 29 days with `node scripts/codex-usage.mjs`; use timestamped changes in cumulative local session counters, including archived and compressed sessions. Cached input is already included in Codex input. Calculate Antigravity for the same period with `node scripts/antigravity-usage.mjs`; its input and cache read are separate. Calculate Meta Muse with `node scripts/meta-muse-usage.mjs` (local `model_completed` session events) and Grok with `node scripts/grok-usage.mjs` (local session `updates.jsonl` turn snapshots) for the same period; their cached input is included in input and reasoning in output. Meta Muse also adds direct API calls that leave no local session log from the manually reported figure in `scripts/meta-muse-api-usage.json` (190M input / 6.2M output as of 2026-11-10); update or zero that file when the reported API total changes, or later windows will keep counting it. Cursor has no local token counters (server-side only): `node scripts/cursor-usage.mjs` reports `localCoverage: false` with zero tokens. Report missing local coverage and do not treat local results as account-wide usage without evidence.

# Antigravity and Gemini

Antigravity is a Gemini-based assistant and can act as a subagent. On this PC, `agy` starts its interactive CLI; a noninteractive `agy --print` request was also verified. Follow [ANTIGRAVITY.md](ANTIGRAVITY.md) and use the [delegate-antigravity skill](.agents/skills/delegate-antigravity/SKILL.md) when delegating to it. For Google search tasks, always delegate to Antigravity when available and permitted; if it cannot perform the search, use an available alternative and explain the limitation. Verify important claims against their sources. Antigravity and Gemini CLI are separate tools.
